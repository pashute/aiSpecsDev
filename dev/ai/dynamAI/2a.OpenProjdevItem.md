## Filename: 2a.OpenProjdevItem.md
**Version:** 0.1.5

# Pseudo:
Goal: Open a GitHub project item to work on within current feature branch

Inputs: item number or URL (optional)

Prerequisites:
- Feature branch exists and is active in Git
- Correct feature is listed in projdev.yaml
- Developer confirmation before opening item
- If active_item exists: check if requested item is subtask or different feature

0. On problems: stop and discuss. (don't overcome alone)

1. Validation:
1.1. Verify item number/URL format
1.2. Verify issue state is "open"
1.3. Verify item belongs to current feature
1.4. If active_item exists: verify requested item is subtask or warn
1.5. If moving to subitem: verify no uncommitted files

2. Action steps:
2.1. Get item number/URL (if not provided)
2.2. Fetch item details from GitHub
2.3. Fetch subitems
2.4. Parse checkbox steps from issue body and comments
2.5. If moving to subitem: save parent progress to projdev.yaml
2.6. Update projdev.yaml with active_item and parent_item
2.7. If returning to parent: restore steps.md from parent progress
2.8. Generate steps in steps.md based on item requirements

3. Expected Results:
- projdev.yaml updated with active_item
- steps.md populated with item steps
- Parent progress preserved if moving to subitem

Reminders:

### Step 1.3 Check active_item context
1.3.1 If active_item exists in projdev.yaml:
  - Check if requested item is a subtask of active_item
  - If yes: Check for uncommitted files using `git status --porcelain`
    - If uncommitted files exist:
      - If only steps.md and projdev.yaml are uncommitted:
        - Check if they reflect a recent completed commit (compare with projdev.yaml commits section)
        - If yes: Notify developer that metadata files are uncommitted but reflect recent commit
        - Consult developer: Should we add a step to commit metadata files only, then re-run dynamAI task?
        - Wait for developer's ok
        - If developer agrees: Add step to steps.md to commit metadata, stop dynamAI task
      - If other files are uncommitted: WARN developer and suggest commit first
      - Do not proceed until files are committed
  - If no: WARN that moving to another feature is not supported
    - Ask developer to close current item first
On result:
- problem: Consult the developer
- no problem: Close step
