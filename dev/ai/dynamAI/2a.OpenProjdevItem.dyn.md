## Filename: 2a.OpenProjdevItem.dyn.md
**Version:** 0.1.8.1

# Pseudo:
Goal: Open a GitHub project item to work on within current feature branch

Inputs: item number or URL (optional)

Prerequisites:
- Feature branch exists and is active in Git
- Correct feature is listed in projmng.yaml
- Developer confirmation before opening item
- If active_item exists: check if requested item is subtask or different feature
- On problems NOTIFY, HALT, and CONSULT

Verifications:
- Verify item number/URL format
- Verify issue state is "open"
- Verify item belongs to current feature
- If active_item exists: verify requested item is subtask or warn
- If moving to subitem: verify no uncommitted files

Steps:
- Get item number/URL (if not provided)
- Fetch item details from GitHub
- Fetch subitems
- Parse checkbox steps from issue body and comments
- If moving to subitem: save parent progress to projmng.yaml
- Update projmng.yaml with active_item and parent_item
- If returning to parent: restore steps.md from parent progress
- Generate steps in steps.md based on item requirements
- Set item stage to "in progress"

Results:
- projmng.yaml updated with active_item
- steps.md populated with item steps
- Parent progress preserved if moving to subitem
- Item stage set to "in progress"

Error handling:
- On error: NOTIFY, HALT, and CONSULT according to halt.dyn.md
