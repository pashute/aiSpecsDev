# Pseudo:
Goal: Close GitHub project item with proper verification and cleanup

Inputs:

## Two-Phase Close Approach
**Phase 1: Close in GitHub** - Advance stage to "in review", create closing comment, close issue, push
**Phase 2: Update metadata** - Update projmng.yaml and steps.md, commit and push metadata

Verifications:
- Verify active_item matches requested item
- Verify all steps.md steps are done (no ? or !)
- Verify item stage is "in progress"
- Verify all files committed/pushed
- Verify subitem status (all closed OR partial close approved)
- Prepare comparison table of project steps vs steps.md

Steps:
- Phase 1: Advance stage to "in review", show summary to developer, create closure note from commits, close item, verify
- Phase 2: Update projmng.yaml (move to completed_items, clear active_item), update steps.md, commit metadata, push, verify
- If parent exists: check recursive close logic
- Suggest next item to work on

Results:
- Item closed in GitHub project
- Closing comment added
- projmng.yaml updated
- Parent recursively closed if applicable
- Metadata committed and pushed

Error handling:
- On error: NOTIFY, HALT, and CONSULT according to halt.dyn.md
