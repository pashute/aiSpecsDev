## Developer confirmations required
This dynamAI requires developer confirmation at the following steps:
- After Step 2 (completion table): confirm before proceeding to commit message
- After Step 4 (show summary): confirm before proceeding to commit/push
- After Step 5 (commit and push): confirm before proceeding to verification
- After Step 6 (verification): confirm before updating projdev.yaml
- After Step 6 (steps cleanup): confirm before proceeding

DO NOT rely on one confirmation for multiple steps. Each confirmation is specific to that step only.

## General commit / push instructions
- Key terms: check in, push, commit, finish 
- Remember before any powershell command or web access, notify what is and what for.
- Remember after any posershell command or web access, notify what you got from it.

  ## Step 7 verify succeeded both
  - Verify success of commit with powershell command: `git log -1 --format="%H %s"`
  - Get commit URL with: `git log -1 --format="%H"` then construct URL: https://github.com/{owner}/{repo}/commit/{hash}
  - Verify success of push with powershell command: `git log origin/{branch}..HEAD` (should be empty if pushed)
  - Get GitHub commit URL: https://github.com/{owner}/{repo}/commit/{hash}
  - Warn and stop if anything goes wrong.
  - Notify if succeeded with commit hash and GitHub URL
  - Update projdev.yaml commits section with commit details (see projdevUpdate.md "On Commit and Push" section for format)

  - Delete completed steps from steps.md up to the commit point
  - If next steps are unclear without context, add telegraphic summary of previous steps (only what's necessary for understanding)

  ## Step 8 add comment to project item
  - Add comment to the GitHub project item with commit hash and link
  - Use gh api to add comment: `gh api repos/{owner}/{repo}/issues/{itemnum}/comments -f body="{commit hash}: {commit URL}"`
