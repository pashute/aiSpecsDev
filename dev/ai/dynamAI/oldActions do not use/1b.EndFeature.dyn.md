# Pseudo:
Goal: End a Gitflow feature branch and merge to develop

Inputs: None (uses current feature from projmng.yaml)

Prerequisites:
- Developer confirmation to proceed
- All items in feature are closed
- Feature branch is clean (committed and pushed)
- Developer's confirmation before closing feature
- On problems NOTIFY, HALT, and CONSULT

Steps:
- Switch to develop branch
- Merge feature branch to develop
- Push develop branch
- Delete feature branch (local and remote)
- Update projmng.yaml (clear feature, active_item, parent_item)
- Clear steps.md
- 2nd phase silent commit and push

Results:
- Feature merged to develop
- Feature branch deleted
- projmng.yaml cleared
- steps.md cleared

Error handling:
- On error: NOTIFY, HALT, and CONSULT according to halt.dyn.md
